# 🎬 Cinematheque Project

**Cinematheque Project** — это учебный проект по веб-разработке, представляющий собой стильный онлайн-кинотеатр с возможностью бронирования билетов в реальные кинотеатры Санкт‑Петербурга. Виртуальная библиотека мирового кинематографа, где собраны фильмы и сериалы от timeless классики до горячих новинок 2026 года, плюс полноценный цикл покупки билетов: от выбора места в зале до электронного билета с QR‑кодом.

Сервис вдохновлён эстетикой кино: тёмная тема с золотыми акцентами, зернистый фон как на старой плёнке и элементы из «Звёздных войн» (включая BB-8 переключатель тем). Проект выполнен в рамках учебной практики **ПМ.02 «Осуществление интеграции программных модулей»** и охватывает полный цикл разработки — от анализа требований до тестирования и оформления портфолио.

## 📖 О проекте

Cinematheque — это единая платформа, которая объединяет каталог фильмов и возможность покупки билетов в кинотеатры. Больше не нужно переходить между сайтами: весь путь от выбора фильма до получения билета — в одном окне.

Основные возможности:

- 🎞️ Каталог фильмов и сериалов — от «Дюны» до «Пацанов» с рейтингами, жанрами и постерами из TMDB.
- 🏢 Кинотеатры Санкт‑Петербурга — список реальных кинотеатров с адресом, метро и рейтингом.
- 📅 Расписание сеансов — по датам, сгруппированное по фильмам, с указанием формата (2D, 3D, IMAX, Dolby) и языка.
- 🪑 Интерактивная схема зала — выбор конкретного места с цветовой индикацией: VIP (красный), Комфорт (синий), Стандарт (зелёный).
- 🔴/🟢 Статусы мест — свободно / занято / выбрано, обновляются в реальном времени.
- 💳 Оформление заказа — форма оплаты с выбором способа (карта, СБП, кошелёк), анимированная банковская карта, имитация платежа.
- 📜 История заказов — все купленные билеты хранятся в личном кабинете, каждый с мини‑QR‑кодом.
- 👤 Система аккаунтов — регистрация, вход, JWT‑токены, роли (гость, пользователь, менеджер, админ), подписка сохраняется на сервере.
- 🌗 Тёмная/светлая тема — переключение BB‑8 тогглом с сохранением выбора.
- 🧪 Демо‑режим — работает без сервера: все данные генерируются на лету, можно тестировать интерфейс.

## 🚀 Установка и запуск

### Без бэкенда (демо‑режим)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/skywaJlker192/cinematicue.git
   ```
2. Откройте `index.html` в любом браузере — приложение автоматически загрузит тестовые данные (кинотеатры, фильмы, сеансы, места).

### Полный запуск с сервером

1. Перейдите в папку `backend`:
   ```bash
   cd backend
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер:
   ```bash
   node server.js
   ```
4. Откройте в браузере:
   - Главная: [http://localhost:3001/index.html](http://localhost:3001/index.html)
   - Кинотеатры: [http://localhost:3001/cinema.html](http://localhost:3001/cinema.html)

### Требования

- Node.js (v16 или выше) — только для бэкенда.
- Современный браузер (2026+ стандарты).
- Для демо‑режима Node.js не требуется.

## 🌐 API Endpoints

| Метод   | Путь                                          | Описание                                     |
|---------|-----------------------------------------------|----------------------------------------------|
| `GET`   | `/api/cinemas`                                | Список кинотеатров с количеством сеансов     |
| `GET`   | `/api/cinemas/:id`                            | Детали кинотеатра                            |
| `GET`   | `/api/cinemas/:id/sessions?date=YYYY-MM-DD`   | Сеансы кинотеатра (с фильтрацией по дате)    |
| `GET`   | `/api/sessions/:id/seats`                     | Схема зала со статусами мест                 |
| `POST`  | `/api/orders`                                 | Создание заказа (бронь мест)                 |
| `PUT`   | `/api/orders/:id/pay`                         | Оплата заказа (имитация)                     |
| `PUT`   | `/api/orders/:id/cancel`                      | Отмена заказа                                |
| `GET`   | `/api/orders?user_token=xxx`                  | История заказов пользователя                 |
| `POST`  | `/api/register`                               | Регистрация нового пользователя              |
| `POST`  | `/api/login`                                  | Вход и получение JWT‑токена                  |
| `GET`   | `/api/profile`                                | Профиль текущего пользователя                |
| `PUT`   | `/api/profile/subscription`                   | Обновление статуса подписки                  |

## 🎨 Дизайн и технологии

### Технологии

- **HTML5** — семантическая разметка (`header`, `main`, `footer`, `article`, `details/summary`).
- **CSS3** — переменные для тем, анимации, Grid/Flexbox для адаптивных лэйаутов, `::before` для зернистого фона.
- **JavaScript (ES6+)** — динамический рендеринг карточек, интерактивная схема зала, работа с REST API, сохранение состояния в `localStorage`.
- **Node.js + Express** — серверная часть: REST API, middlewares (CORS, JSON‑парсинг, статические файлы).
- **JSON‑файл как БД** — лёгкое хранение данных без установки СУБД, автоматическая генерация тестового наполнения.
- **JWT + bcrypt** — безопасная аутентификация и хранение паролей.
