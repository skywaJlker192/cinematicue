## Вариант 1: Без бэкенда (просто открыть в браузере)

Просто открой `index.html` в браузере — сайт работает в **демо-режиме**:
- Кинотеатры, сеансы и места генерируются локально
- Заказы сохраняются в localStorage браузера
- Оплата имитируется

```
cinematicue/
├── index.html       ← открой это
├── cinema.html
├── css/
│   ├── style.css
│   └── cinema.css   ← новый
├── js/
│   ├── catalog.js
│   ├── cinema.js    ← новый
│   └── wheel.js
└── backend/         ← для полного режима
```

## Вариант 2: С бэкендом (полный режим)

### Требования
- Node.js 18+ (скачать: https://nodejs.org)

### Установка и запуск

```bash
# 1. Перейди в папку backend
cd cinematicue/backend

# 2. Установи зависимости (один раз)
npm install

# 3. Запусти сервер
node server.js
```

Сервер запустится на `http://localhost:3001`

### Открытие сайта
После запуска сервера открой в браузере:
```
http://localhost:3001
```
или просто открой `index.html` напрямую — он автоматически найдёт бэкенд.

## API эндпоинты (при запущенном бэкенде)

| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/cinemas | Список кинотеатров |
| GET | /api/cinemas/:id/sessions | Сеансы кинотеатра |
| GET | /api/sessions/:id/seats | Схема мест сеанса |
| POST | /api/orders | Создать заказ |
| PUT | /api/orders/:id/pay | Оплатить заказ |
| PUT | /api/orders/:id/cancel | Отменить заказ |
| GET | /api/orders?user_token=xxx | История заказов |

## Структура бэкенда (SQLite таблицы)

```
cinemas → halls → sessions → seats
                           ↓
                    orders → tickets
```

База данных создаётся автоматически при первом запуске: `backend/cinematheque.db`

---

## Возможные проблемы

**"npm не найден"** → Установи Node.js с nodejs.org

**Сайт работает в демо-режиме** → Это нормально, запусти бэкенд по инструкции выше

**Порт 3001 занят** → Измени PORT в backend/server.js и API в js/cinema.js
