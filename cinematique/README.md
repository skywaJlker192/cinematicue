# 🎬 Cinematheque Project

**Cinematheque Project** — это учебный проект по веб-разработке, представляющий собой стильный онлайн-кинотеатр. Виртуальная библиотека мирового кинематографа, где собраны фильмы и сериалы от timeless классики до горячих новинок 2026 года. Сервис вдохновлён эстетикой кино: тёмная тема с золотыми акцентами, зернистый фон как на старой плёнке и элементы из «Звёздных войн» (включая BB-8 переключатель тем).

---

## 📖 О проекте

Cinematheque — не просто сайт, а погружение в мир кино. Здесь вы найдёте:

- 🎞️ **Каталог фильмов и сериалов** — от «Дюны» до «Пацанов» с рейтингами, жанрами и постерами из TMDB.
- 💎 **Тарифные планы** — Базовый, Стандарт и Премиум с описанием преимуществ (4K, HDR, Dolby Atmos).
- ❓ **FAQ и контакты** — полезные ответы и форма обратной связи.
- 🌗 **Темы оформления** — тёмная (по умолчанию) и светлая, с плавными переходами и сохранением выбора в `localStorage`.

Проект разработан как демонстрация навыков вёрстки: **responsive дизайн**, **CSS-анимации** (например, BB-8 toggle и футуристический поиск), **CSS-переменные** для тем и эффект **зернистости фона** для кинематографической атмосферы.

## 🚀 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/cinematheque-project.git
   ```
2. Откройте `index.html` в любом браузере — сервер не требуется!
3. Для тестирования тем используйте **BB-8 toggle** в шапке сайта.

### Требования

- Современный браузер (2026+ стандарты).
- Нет зависимостей — чистый HTML/CSS.

---

## 🎨 Дизайн и технологии

### Технологии

- **HTML5** — семантическая структура (`header`, `main`, `footer`).
- **CSS3** — переменные, анимации, grid/flexbox для лэйаутов, `::before` для зернистого фона.

### Дизайн-фичи

#### ✨ Зернистый фон (имитация плёнки)

```css
body::before {
  content: '';
  position: fixed;
  inset: 0;
  background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 200 200' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='n'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.7' numOctaves='3' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23n)' opacity='0.04'/%3E%3C/svg%3E");
  pointer-events: none;
  z-index: 9999;
}
```

- **Тёмная и светлая темы** — реализованы через CSS-переменные.
- **Анимации** — BB-8 toggle, hover-эффекты на карточках.
- **Без JS (кроме сохранения темы)** — вся интерактивность на чистом CSS (checkbox для toggle).
